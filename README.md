# 🏨 The Wild Oasis

The Wild Oasis is a hotel management web application built with React.js. It provides an intuitive dashboard for managing hotel operations, including bookings, cabins, guests, and check-in/check-out processes.

The project focuses on building a complete, data-driven application using modern React tools, backend integration, and reusable components.

### ✨ Features

- **Dashboard:** View important hotel statistics and booking information.
- **Booking Management:** View booking details and manage reservations.
- **Cabin Management:** Manage hotel cabins and their information.
- **Check-in & Check-out:** Handle guest check-in and checkout operations.
- **Authentication:** Secure user login and account management.
- **Data Management:** Create, read, update, and delete application data.
- **Dark Mode:** Switch between light and dark themes.
- **Interactive UI:** Responsive layouts, reusable components, and smooth navigation.

### 🛠️ Technologies Used

- **React.js** – Building reusable and interactive UI components.
- **React Router** – Managing application navigation and routing.
- **Supabase** – Backend services, database, authentication, and storage.
- **React Query (TanStack Query)** – Managing server state and data fetching.
- **Context API** – Managing global application state and sharing data across components.
- **Styled Components** – Component-based styling.
- **React Hook Form** – Managing forms and form validation.
- **Recharts** – Creating dashboard charts and data visualizations.
- **Vite** – Development environment and build tool.
